## 🚀 Architecture & Automation Stack
- **Storefront:** Next.js 16 (App Router), Turbopack, Tailwind CSS, TypeScript, deployed on Vercel.
- **Database & State:** Supabase Cloud PostgreSQL with Row-Level Security (RLS) and Dual-Keyed Order Tracking (	rack_order RPC).
- **Automation Engine:** GitHub Actions (Nightly Health Sentinel, Radha CEO Reflection, Arjun Procurement Sentinel).
- **Logistics:** Delhivery, BlueDart, DTDC with automated 1-Click WhatsApp COD intent verification.
