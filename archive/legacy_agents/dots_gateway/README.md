# Hermes Dots Gateway (OpenAI Dots Architecture Clone)

A web-based dashboard wrapper, execution sandbox, and API gateway for a self-hosted **Hermes Agent** instance, turning it into an exact clone of **OpenAI Dots**.

---

## 🏗 Architecture Specifications

### 1. Back-end Service & Harness Integration
- **Direct LLM Orchestration:** Interfaced to OpenAI-compatible endpoints (OpenRouter, Gemini, Anthropic, or local vLLM).
- **Long-term Memory Persistence:** Automatically reads and writes `~/.hermes/MEMORY.md` and `USER.md` (with fallbacks to workspace `RADHA_MEMORY/`).

### 2. Always-On Multi-Trigger Gateway
- **24/7 Background Scheduler:** Uses an asynchronous background loop checking active interval tasks continuously without sleeping.
- **Webhook Receiver (`/api/v1/dot-triggers`):** Accepts external events (GitHub, Stripe, custom crons) and forces Hermes Agent out of `IDLE`/`Sleeping` state to execute workflows.
- **Customizable Cron Scheduler UI:** Create, enable/disable, and trigger recurring prompt tasks directly from the dashboard.

### 3. Sandboxed Execution Viewer
- **Streaming Shell Execution:** Executes real bash/PowerShell commands in an isolated workspace process.
- **WebSocket Streaming (`/ws/terminal/{session_id}`):** Real-time `stdout`, `stderr`, and `stdin` broadcasting directly to an xterm-style visual terminal widget.
- **Dynamic File Explorer:** Traversal-safe file browser that inspects files generated by the agent with syntax preview and download buttons.

### 4. Human-In-The-Loop Security & Approvals
- **State Machine Interceptor:** Destructive commands matching protected patterns (`rm -rf`, `drop table`, `delete from`, `git push`, etc.) are intercepted.
- Shifts state to `AWAITING_APPROVAL` and blocks execution using an `asyncio.Event`.
- Triggers interactive approval cards in the UI with `[Approve Action]` and `[Reject & Adjust Prompt]`.

### 5. Frontend Theme & "Vibe" UI (OpenAI Dots Aesthetic)
- Dark obsidian layout (`#070709`) with glowing radial aurora blobs.
- Dynamic **Sticky Agent Status Badge**: "Sleeping", "Thinking", "Running Code", "Awaiting Approval", "Completed".
- **Split-Pane Layout:** Persistent Left Chat Thread + Right Canvas Workspace (Sandbox Terminal, Live Artifact Canvas, File Explorer, 24/7 Crons, Long-term Memory).
- Animated visual orb avatar reacting to state changes.

## 🚀 Quickstart

### Local Setup
```bash
# 1. Install dependencies
pip install -r dots_gateway/requirements.txt

# 2. Start the Dots Gateway API
python start_dots.py

# 3. Start Next.js Storefront / Dashboard (in storefront/)
cd storefront
npm run dev
```

Visit: `http://localhost:3002/dots`

### Docker Deployment
```bash
docker build -t hermes-dots -f dots_gateway/Dockerfile .
docker run -p 8000:8000 --env-file .env hermes-dots
```
